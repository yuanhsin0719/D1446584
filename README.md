## 4. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上引號的 `"4"` 屬於**字串（`str`）**型別，電腦會把它當成單純的「文字」而非可以加減乘除的數值。本題需要將應付總額除以人數（`total_amount / people`），如果直接拿數字除以字串，Python 會因為型別不相容而報錯（`TypeError`）。因此，必須先用 `int("4")` 把它轉成**整數（`int`）**型別的 `4`，程式才能正常執行數學除法運算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **應付總額會變成 `1,210` 元。**
* **計算過程：**
  * 先扣折價券後的餐費：$1,200 - 100 = 1,100$ 元
  * 依剩餘餐費算服務費：$1,100 \times 10\% = 110$ 元
  * 最終應付總額：$1,100 + 110 = 1,210$ 元
* **不同的原因：** 題目規定「服務費必須以原始餐費（1,200 元）計算」，因此服務費是 $1,200 \times 10\% = 120$ 元，總額為 $1,220$ 元。若先扣除 100 元折價券再算服務費，計算服務費的基準金額會變小，導致服務費少算了 $100 \times 10\% = 10$ 元，最後應付總額也就跟着少了 10 元。
